# Documentação da API

Na raiz do projeto, com Doxygen instalado, execute:

```bash
doxygen Doxyfile
```

O HTML será criado em `docs/html/`. Abra `docs/html/index.html` no navegador. As entradas são os cabeçalhos públicos, a demonstração e o README, conforme o `Doxyfile`.

Este pacote fornece o comando de geração documentado, alternativa expressamente permitida na seção “Entregáveis” do enunciado. O HTML gerado não está incluído neste pacote. Doxygen é uma ferramenta de documentação e não uma dependência do programa C++.
